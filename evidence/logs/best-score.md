# 카테고리별 최고 점수 검증

- 수행일: 2026-08-05
- 환경: macOS / zsh / Python 3.12.13
- 실행 방식: 사용자 터미널에서 `py`로 직접 실행
- 개인정보 보호: 셸 프롬프트의 계정명과 호스트명 제외

## 플레이 전 조회

```console
=== 카테고리별 최고 점수 ===
과학: 기록 없음
역사: 기록 없음
```

과학과 역사 모두 플레이 전에는 `기록 없음`으로 표시됐다.

## 과학 퀴즈 플레이

```console
=== 퀴즈 결과 ===
정답 수: 1/2
점수: 50점
새로운 최고 점수: 50점
```

과학 문제 2개 중 1개를 맞혀 50점이 계산되고 첫 최고 점수로 등록됐다.

## 플레이 후 조회

```console
=== 카테고리별 최고 점수 ===
과학: 50점
역사: 기록 없음
```

플레이한 과학은 50점, 플레이하지 않은 역사는 `기록 없음`으로 표시됐다.
메뉴 5번 선택 후 `게임을 종료합니다.` 안내와 함께 정상 종료했다.

## 낮은 점수 유지 확인

동일 실행에서 과학 50점을 기록한 뒤 다시 0점으로 플레이했다. 메뉴 4번에서
과학 최고 점수가 50점으로 유지되는 것을 직접 실행으로 확인했다.

## 판정

- 플레이 전 상태 안내: 확인 완료
- 첫 최고 점수 등록: 확인 완료
- 카테고리별 점수 조회: 확인 완료
- 낮은 점수에서 기존 최고 기록 유지: 확인 완료
