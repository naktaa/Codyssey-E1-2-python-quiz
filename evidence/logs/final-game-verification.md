# 최종 게임 기능 직접 실행 기록

- 수행일: 2026-08-09
- 환경: macOS / zsh / Python 3.12.13
- 실행 방식: 사용자 터미널 직접 실행
- 실행 명령: `py --test`
- 사용 파일: Git에서 제외된 `state.test.json`
- 정리 방식: 사용자가 제공한 실제 출력에서 반복되는 메인 메뉴는 줄이고 기능별로
  재배치했다. 의미 없는 입력 앞뒤 공백만 정리하고 출력 문구와 입력 내용은
  유지했다.

> 현재성 안내: 이 문서는 2026-08-09 당시의 실제 출력 증거이므로 문제별
> `1점을 획득했습니다`, `3점을 획득했습니다` 문구를 그대로 보존한다. 2026-08-10
> 이후 코드는 정오답 안내 뒤에 `현재 점수`를 별도로 표시한다. 최신 코드의 점수
> 경계는 [현재 점수 회귀 검사](current-score-regression.md)로 확인했다. 이 macOS 직접
> 실행 기록과 최종 코드 회귀 검사를 함께 최종 기능 증거로 사용한다.

## 확인 결과 요약

| 항목 | 직접 확인한 결과 |
|---|---|
| 테스트 데이터 분리 | 시작 시 `state.test.json` 사용 안내 출력 |
| 메인 메뉴 | 등록 문제 수, 최고 점수와 메뉴 1~6 출력 |
| 퀴즈 추가 | 문제·선택지 4개·정답·힌트 입력 후 즉시 저장 |
| 빈 입력 검증 | 빈 힌트를 거부하고 다시 입력 |
| 퀴즈 목록 | 추가 직후 문제 수가 5개에서 6개로 증가하고 새 문제 표시 |
| 무작위 출제 | 6개 중 3개를 선택해 저장 순서와 다른 순서로 출제 |
| 시간·힌트 | 문제당 10초, 5초 후 자동 힌트 규칙 안내와 실제 힌트 공개 |
| 점수 | 힌트 후 정답 1점, 힌트 전 정답 3점, 오답 0점 |
| 최종 결과 | 정답 수 `2/3`, 힌트 1회, 최종 점수 4점 출력 |
| 점수 기록 | 최고 점수 7점과 방금 완료한 4점 기록을 포함한 최근 5건 출력 |
| 퀴즈 삭제 | 추가한 문제를 확인 후 삭제하고 목록을 기본 5개로 복원 |
| 정상 종료 | 종료 메뉴에서 안내 후 traceback 없이 종료 |

## 1. 테스트 모드와 메인 메뉴

```console

========================================
등록 문제: 5개 | 최고 점수: 7점
----------------------------------------
1. 퀴즈 풀기
2. 퀴즈 목록 보기
3. 최고 점수와 기록

6. 종료
----------------------------------------
메뉴 선택(1~6): 4
```

시작 직후 이전 플레이의 최고 점수 7점이 복원된 상태도 함께 확인됐다.

## 4. 제한 시간 퀴즈와 점수 계산

```console
========================================
퀴즈 풀기
========================================
등록된 상식 퀴즈는 총 6문제입니다.
풀 문제 수를 입력하세요(1~6): 3

========================================
상식 퀴즈 시작
========================================
선택한 문제: 3개
제한 시간: 10초 | 힌트: 5초 후 공개

----------------------------------------
[문제 1/3]
물의 화학식은 무엇인가요?
  1) CO2
  2) H2O
  3) O2
  4) NaCl
힌트: 수소 원자 두 개와 산소 원자 한 개로 이루어져 있습니다.
남은 시간: 3초 | 정답 번호(1~4): 2
정답입니다! 1점을 획득했습니다.

----------------------------------------
[문제 2/3]
훈민정음을 창제한 왕은 누구인가요?
  1) 세종
  2) 태조
  3) 영조
  4) 정조
힌트:
남은 시간: 6초 | 정답 번호(1~4): 1
정답입니다! 3점을 획득했습니다.

----------------------------------------
[문제 3/3]
지구의 자연 위성은 무엇인가요?
  1) 태양
  2) 화성
  3) 달
  4) 금성
힌트:
남은 시간: 8초 | 정답 번호(1~4): 2
오답입니다. 정답은 3번 달입니다.

========================================
퀴즈 결과
========================================
정답 수: 2/3
힌트 사용 횟수: 1회
최종 점수: 4점
```

터미널 카운트다운은 같은 줄을 갱신하므로 복사된 로그에는 제출 시점의 남은 시간만
남는다. 첫 문제는 힌트 공개 후 정답으로 1점, 두 번째 문제는 힌트 공개 전 정답으로
3점, 세 번째 문제는 오답으로 0점이 반영됐다.

## 이번 기록의 범위

- 현재 메뉴, 퀴즈 추가·목록·플레이·점수 기록·삭제·정상 종료를 한 실행에서
  확인했다.
- 시작 시 최고 점수 7점이 복원되어 기존 점수의 재실행 영속성을 확인했다.
- 추가한 퀴즈는 같은 실행에서 삭제했으므로, 추가 퀴즈의 종료 후 재실행 복원은
  이번 기록만으로 확인하지 않았다.
- 시간 초과, `Ctrl+C`, EOF와 손상 JSON 복구는 기존 개별 증거와 회귀 검사 기록을
  사용한다.
