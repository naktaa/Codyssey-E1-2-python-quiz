## 현재 구조

- `Quiz`: 퀴즈 데이터, 형식 검증, 출력과 JSON 변환
- `GameManager`: 메뉴, 입력, 퀴즈 진행, 추가·삭제와 점수 처리
- `StateManager`: JSON 저장·불러오기, 검증과 손상 복구
- `TimedTerminalInput`: 제한 시간, 카운트다운과 자동 힌트 입력
- `main.py`: 기본 객체 생성과 실행

`main.py`가 실행 옵션에 맞는 상태 경로를 선택하고 `StateManager`를 생성한다.
`GameManager`에는 생성된 `StateManager`만 전달한다. `GameManager`의 `save_state()`와
`load_state()`는 현재 상태 전달과 반영을 담당하고 실제 파일 처리는 하지 않는다.
기본 퀴즈는 정상 상태 파일을 읽을 때 만들지 않고 파일이 없거나 손상됐을 때만
`StateManager._create_default_state()`에서 생성한다.

## 구현 완료

### 필수 기능

- 메뉴 1~6과 공통 정수·문자열·`y/n` 입력 검증
- 4지선다형 `Quiz` 클래스와 직접 작성한 기본 문제 5개
- 전체 상식 문제 중 풀이 수 선택과 무작위 출제
- 정답·오답·결과 출력과 단일 최고 점수 관리
- 퀴즈 추가, 목록, 삭제와 즉시 저장
- 프로젝트 루트 `state.json` 저장과 재실행 복원
- UTF-8 JSON 읽기·쓰기와 임시 파일 교체
- 파일 없음·문법 오류·스키마 오류 처리
- 손상 파일 백업 후 기본 데이터 복구
- 정상 종료, `Ctrl+C`, EOF 안전 종료

### 추가 기능

- 문제별 10초 제한 시간과 1초 카운트다운
- 5초 후 문제별 자동 힌트
- 정답 3점에서 힌트 사용 시 2점을 차감하는 점수
- 메뉴·기능별 공통 구분선과 문제 진행 수 표시
- 문제 수 선택과 중복 없는 무작위 출제
- 퀴즈 삭제와 저장 실패 롤백
- 전체 플레이 기록 저장과 최근 5개 표시
- 실제 상태와 분리된 `--test` 실행 옵션

## 점수 정책

- 최고 점수는 실제 획득 점수끼리 비교한다.
- 문제 수에 따른 백분율이나 정규화 점수는 사용하지 않는다.
- 많은 문제를 선택할수록 획득 가능한 최대 점수가 높아지는 현재 동작을 유지한다.
- 이 정책은 추가 고려사항이 아니라 확정된 게임 규칙이다.
