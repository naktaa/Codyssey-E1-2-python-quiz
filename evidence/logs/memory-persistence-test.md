# 메모리 기반 퀴즈 추가와 재실행 비교

- 수행일: 2026-08-04
- 환경: macOS / zsh / Python 3.12.13
- 실행 명령: `py main.py`
- 검증 방식: 사용자 터미널 직접 실행
- 개인정보 보호: 셸 프롬프트의 계정명과 호스트명은 제외

## 검증 목적

JSON 저장을 연결하기 전의 메모리 기반 퀴즈 추가 동작을 확인한다. 퀴즈가
실행 중에는 추가되지만 프로그램을 종료하고 다시 실행하면 유지되지 않는지
검증해, 이후 `state.json` 영속성 구현 결과와 비교할 기준 로그로 사용한다.

## 1차 실행 — 퀴즈 추가

```console
$ py main.py

=== 상식 퀴즈 게임 ===
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록 보기
4. 카테고리별 최고 점수
5. 종료
메뉴를 선택하세요: 2

=== 퀴즈 추가 ===
카테고리 이름: 과학
문제: test
선택지 1: 1
선택지 2: 2
선택지 3: 3
선택지 4: 4
정답 번호(1~4): 6
1부터 4 사이의 숫자를 입력해 주세요.
정답 번호(1~4): 1
퀴즈를 추가했습니다.

=== 상식 퀴즈 게임 ===
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록 보기
4. 카테고리별 최고 점수
5. 종료
메뉴를 선택하세요: 5
게임을 종료합니다.
```

### 1차 실행에서 확인한 내용

- 과학 카테고리에 `test` 문제를 추가했다.
- 정답 번호로 범위 밖의 값 `6`을 입력하자 오류 안내 후 다시 입력받았다.
- 정상 범위인 `1`을 입력하자 `퀴즈를 추가했습니다.`가 출력됐다.

## 2차 실행 — 재실행 유지 여부 확인

```console
$ py main.py

=== 상식 퀴즈 게임 ===
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록 보기
4. 카테고리별 최고 점수
5. 종료
메뉴를 선택하세요: 1

=== 카테고리 선택 ===
1. 과학
2. 역사
카테고리를 선택하세요: 1

=== 과학 퀴즈 ===

1. 물의 화학식은 무엇인가요?
   1) CO2
   2) H2O
   3) O2
   4) NaCl
정답 번호를 입력하세요: 2
정답입니다!

2. 지구의 자연 위성은 무엇인가요?
   1) 태양
   2) 화성
   3) 달
   4) 금성
정답 번호를 입력하세요: 2
오답입니다. 정답은 3번 달입니다.

=== 퀴즈 결과 ===
정답 수: 1/2
점수: 50점

=== 상식 퀴즈 게임 ===
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록 보기
4. 카테고리별 최고 점수
5. 종료
메뉴를 선택하세요: 5
게임을 종료합니다.
```

### 2차 실행에서 확인한 내용

- 재실행 후 과학 카테고리에는 기본 문제 2개만 출제됐다.
- 1차 실행에서 추가했던 `test` 문제는 출제되지 않았다.
- `self.quizzes.append()`로 변경한 메모리 데이터는 Python 프로세스 종료와
  함께 사라지는 것을 확인했다.

## 검증 결과

| 확인 항목 | 실제 결과 | 판정 |
|---|---|---|
| 퀴즈 입력 및 추가 | `test` 문제 추가 성공 | 확인 완료 |
| 잘못된 정답 번호 처리 | `6`을 거부하고 재입력 | 확인 완료 |
| 메모리 데이터 재실행 유지 | 재실행 후 `test` 문제 없음 | 유지되지 않음 |
| JSON 파일 영속성 | 현재 `main`에는 저장·불러오기 없음 | 추후 검증 |

## JSON 적용 후 비교 계획

`state.json` 저장·불러오기를 완성한 뒤 같은 절차로 다시 실행한다. 그때는
프로그램을 종료하고 재실행해도 과학 카테고리에 기본 문제 2개와 추가한
`test` 문제까지 총 3개가 출제되는 것이 정상 기준이다.
