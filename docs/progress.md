## 다음 권장 작업 하나

다음 커밋 전에 이 저장소의 Git 사용자 이름과 이메일을 로컬 범위로 명시하고 설정값을 확인한다.

## 다음 단계 정상 완료 기준

- `git config --local user.name`에 사용할 이름이 표시됨
- `git config --local user.email`에 사용할 이메일이 표시됨
- 설정값을 저장소나 증거에 불필요하게 노출하지 않음
