# 문제별 현재 점수 회귀 검사

- 수행일: 2026-08-10
- 환경: Linux / bash / Python 3.12.3
- 브랜치: `main`
- 기준 커밋: `1716e71`
- 검사 방식: 임시 메모리 상태 관리자와 고정된 제한시간 입력 결과를 사용한 격리
  Python 스크립트

## 검사 목적

- 정답이면 기본 3점을 현재 점수에 즉시 반영한다.
- 힌트가 공개된 뒤 맞힌 정답에만 2점을 차감한다.
- 힌트가 공개됐더라도 오답과 시간 초과에는 점수를 차감하지 않는다.
- 각 문제 결과 뒤에 현재 누적 점수를 출력한다.
- 문제별 `N점을 획득했습니다` 문구는 더 이상 출력하지 않는다.

## 실제 확인 결과

| 입력 결과 | 힌트 공개 | 반환 점수 | 확인한 출력 |
|---|---:|---:|---|
| 정답 | 아니요 | 3점 | `현재 점수: 3점` |
| 정답 | 예 | 1점 | `현재 점수: 1점` |
| 오답 | 예 | 0점 | `현재 점수: 0점` |
| 시간 초과 | 예 | 0점 | `시간 초과입니다.` 다음 `현재 점수: 0점` |

실제 검사 완료 출력은 다음과 같다.

```console
현재 점수 3/1/0/0, 메뉴 디스패치, 백업 충돌, JSON 4칸 저장 검증 완료
```

추가로 다음 항목을 같은 스크립트에서 확인했다.

- 출력 전체에 `점을 획득` 문구가 없음
- 메뉴 2가 목록 메서드를 호출함
- 메뉴 6이 안전 종료 메서드를 호출한 뒤 실행 반복을 끝냄
- 같은 초의 손상 백업 두 개가 기본 이름과 `-1` 순번으로 각각 생성됨
- 상태 JSON이 UTF-8 한글과 4칸 들여쓰기로 저장됨
- Python 소스 6개의 구문 검사가 통과함

## 증거 범위

이 검사는 점수 계산과 메뉴·파일 회귀를 격리된 Linux 환경에서 확인한 코드 회귀
검사다. 실제 macOS 터미널의 카운트다운과 최신 `현재 점수` 화면은
`python3 main.py --test`로 별도 직접 확인해야 한다.
