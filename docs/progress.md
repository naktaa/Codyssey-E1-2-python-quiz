## 확정된 설계

- 카테고리는 각 퀴즈의 `category` 값에서 자동 생성
- 플레이 전 한 카테고리를 선택하고 해당 문제를 저장 순서대로 출제
- 최고 점수는 카테고리별 0~100점으로 `best_scores`에 저장
- 기본 문제는 당분간 비워 두고 테스트 fixture로 기능 검증

## 나중에 필요한 사용자 데이터

- 실제 상식 퀴즈 카테고리
- 직접 작성한 기본 문제와 정답 최소 5개

## 다음 권장 작업 하나

메뉴 1~5와 공통 숫자·문자열 입력을 담당하는 최소 `QuizGame` 골격을 구현한다.

## 다음 단계 정상 완료 기준

- `python3 main.py` 실행 시 메뉴 1~5가 표시됨
- 공백이 있는 정상 숫자를 허용함
- 빈 입력, 문자와 범위 밖 입력을 안내하고 다시 받음
- 메뉴 5를 선택하면 traceback 없이 종료함
- 관련 `unittest`, 컴파일과 `git diff --check`가 통과함

## 차단 요소

- 메뉴와 공통 입력 구현을 막는 요소는 없다.
- 실제 기본 퀴즈 완성 전에는 사용자 문제 데이터가 필요하다.
- `evidence/git/git-log.png`의 로컬 계정명·호스트명은 공개 전 최종 점검이 필요하다.
